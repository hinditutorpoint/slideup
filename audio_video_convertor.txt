ENHANCED AUDIO/VIDEO CONVERTER — ANDROID ONLY

This file defines the complete feature requirements for adding an Enhanced Audio/Video Converter to the existing Flutter Android application.

IMPORTANT:
The application already has FFmpeg integrated.

Use the existing FFmpeg integration.
Do NOT replace it with another FFmpeg package unless absolutely necessary.
Do NOT build a server-side converter.
All media conversion must happen locally on the Android device.

* Android Foreground Service
* Existing background-service implementation

* Native Android service where required

Do NOT rely only on a Flutter widget or UI isolate.

The conversion worker must be independent from the converter screen.
